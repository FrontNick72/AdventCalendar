# Письма для Даши

Мобильный квест в иллюстрированном зимнем доме: три комнаты по пять тайников, ступенчатые подсказки, сохранение после каждого действия. После 15 находок открывается стол со всеми конвертами: можно выбрать письмо, прочитать и вернуться к нему позже. Содержание пока черновое, реальные подарки и номера упаковки не назначены.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
```

Открыть `http://127.0.0.1:5173/` в браузере на этом компьютере. Сервер слушает только локальный адрес, сайт не опубликован. Шрифты и графика загружаются из проекта, внешних сервисов во время игры нет.

```sh
npm run build
npm test
```

Первый вызов проверяет TypeScript и создаёт статическую сборку `dist/`. Второй запускает проверки правил игры, сохранения и содержания. `npm run preview` позволяет посмотреть готовую сборку локально по адресу, который напечатает сервер.

Основное целевое устройство — iPhone 15 Pro с Safari. Для повторной проверки WebKit:

```sh
npx playwright install webkit
npm run test:iphone
```

Профиль устройства использует 393×659 доступных CSS-пикселей при открытых панелях Safari и плотность 3×; дополнительно проверяются полный экран 393×852, безопасные отступы, длинное письмо с увеличенным текстом, поворот и уменьшенная анимация. При горизонтальном положении сохраняется вертикальная композиция с обычной прокруткой страницы. Проверки не заменяют финальный проход на физическом iPhone с конкретной версией iOS.

## Где менять содержание

- `content/advent.json` — рабочий файл, который читает приложение: 15 постоянных ID. Пока все письма черновые, подарки и номера свёртков не назначены.
- `content/prototype.json` — сохранённый пример первого прототипа с условным № 12; приложение его больше не использует.
- `content/advent.example.json` — исходный шаблон.
- `src/scenes/house.ts` — комнаты, координаты предметов, тайники и подсказки. Каждый тайник ссылается на постоянный `letterId`.

Поля описаны в `IMPLEMENTATION_PLAN.md`. `paragraphs` — массив абзацев, `signature` — массив строк подписи, `packageNumber` — номер упаковки, `pickupNote` — необязательное указание, где забрать сюрприз. Текст отображается как обычный текст, HTML в данных не выполняется.

Содержание встроено в сборку. В режиме разработки Vite подхватит изменения автоматически; после публикации для обновления понадобится новая сборка. Не менять `id` уже используемых писем при редактуре текста.

Перед окончательным вручением можно проверить заполнение полного календаря:

```sh
npm run check:content
```

Сейчас эта команда ожидаемо сообщит о незаполненных черновиках. Она требует 15 готовых писем, уникальные номера упаковки 1–15 и уникальные ссылки на позиции авторского реестра. Готовность черновика не означает покупку подарка; программа не изменяет реестр.

## Прогресс

Хранится в `localStorage` текущего браузера и адреса, отдельно от JSON. Ключ полного дома — `dasha-winter:house-15:v2`. Старый ключ `dasha-winter:prototype-one-letter:v1` не читается и не меняется: одна демонстрационная находка не засчитывается в полный поиск. Отдельно сохраняются текущая комната, открытые тайники, находки, чтение и распаковка. После завершения поиска повторный вход ведёт к столу.

В настройках (значок справа сверху) можно начать заново с подтверждением. Сбрасывается только сохранение полного дома. Отметка распаковки доступна для готового письма с номером упаковки; её можно отменить непосредственно в письме. Черновики показываются явно и не предлагают отметить распаковку не назначенного подарка. При повреждении сохранения оригинал не перезаписывается: в настройках доступно скачивание исходных данных. При запрете хранилища игра работает в текущем сеансе и предупреждает об отсутствии сохранения.

Перенос прогресса между устройствами, полный экспорт/импорт и синхронизация ещё не реализованы.

## Графика

- `public/assets/room-clean.png` — фон уголка без текста, конвертов и интерактивных предметов; `room.png` сохранён как исходник.
- `public/assets/desk.png` — стол без текста и писем.
- `public/assets/cushion.png` — отдельная подушка с прозрачным фоном.
- `public/assets/tree-clean.png`, `study-clean.png` — новые комнаты: ёлка и кабинет, очищенные от неподвижных дублей подвижных предметов. `tree.png` и `study.png` — исходники.
- `public/assets/props-atlas.png` — прозрачный атлас девяти рисованных предметов; из него получены отдельные подвижные слои.
- `docs/design/game-assets.json` — исходные промпты и ссылки на референсы; встроенный инструмент `image_gen.imagegen`.
- `docs/design/house-assets.json` — промпты второго этапа, устройство слоёв и соответствие тайникам.
- `docs/design/clean-backgrounds.json` — промпты очистки фонов для подвижных предметов.
- `docs/design/mockups/` — одобренные визуальные ориентиры.

Конверты, бумага, надписи и элементы управления сделаны в HTML/CSS/SVG. Предметы — отдельные прозрачные изображения: после нажатия слой сдвигается, появляется конверт, после находки он исчезает. Фоны остаются иллюстрацией, декоративные детали сами по себе не являются тайниками.

В браузер загружаются только WebP, нужные для текущей сцены: все игровые изображения вместе около 1,38 МБ, первая комната около 0,43 МБ. Исходные PNG сохранены для редактирования. Для повторной подготовки WebP и нарезки атласа:

```sh
npm run optimize:assets
```

Оптимизация использует `sharp` только при разработке; в браузере эта библиотека не загружается.

## Проверка

Результаты полного прохода — в `docs/qa/house-verification.md`; историческая проверка первого прототипа — в `docs/qa/prototype-verification.md`. Полный поиск и все 15 писем проверены в Chromium при 390×844 и 320×620, а также в WebKit с профилем iPhone 15 Pro: четыре сквозных теста проверяют обычную и уменьшенную анимацию, восстановление, безопасные отступы, длинный текст и поворот. Физический iPhone с конкретной версией Safari пока не проверен. Экспорт/импорт прогресса и финальный переход с зажиганием лампы — следующий этап.
