# Как продолжить в личном Codex

## Перенос

1. Скопируй `AdventCalendarForDasha-personal-handoff.zip` на личный компьютер или в личную папку для проекта.
2. Распакуй архив. Внутри будет папка `AdventCalendarForDasha` с четырьмя Markdown-файлами.
3. В Codex под личным аккаунтом открой эту папку как локальный проект и создай новый чат.
4. Отправь сообщение из блока ниже. Сохранённые файлы передадут контекст, поэтому пересказывать переписку не потребуется.

Если продолжаешь на том же компьютере, достаточно распаковать архив в отдельную личную папку и открыть её в личном Codex.

Архив содержит только документы этого личного проекта. В него не входят настройки Codex, авторизация, ключи, рабочие интеграции, локальные журналы и скрытые служебные папки.

Это передача файлов и контекста для нового чата. Она не удаляет и не изменяет уже существующий чат в рабочем аккаунте. Удаление исходных файлов или чата в рамках этой задачи не выполнялось.

## Первое сообщение в новом чате

```text
Продолжаем мой личный проект: новогодний адвент-календарь для жены Даши.

Прочитай AGENTS.md, PLAN.md и HANDOFF.md в этой папке. Общайся со мной на русском.

Мы уже выбрали концепцию: мобильный сайт-квест в уютном зимнем доме. Даша ищет 15 спрятанных писем, видит счётчик. После сбора всех писем открывается стол с уютной лампой и конвертами. На них надписи, в каком настроении их открыть. Внутри — моё личное послание и номер непрозрачно упакованного подарка в большой коробке.

Это личный проект. Рабочие сервисы, интеграции, репозитории и учётные данные не используй. Сайт пока не реализован, финальный список подарков ещё не готов. Не меняй статусы подарков и не распределяй их по дням без моего указания.

Следующий шаг: предложи 2–3 конкретных визуальных направления для дома и стола, подходящих для телефона, и объясни, как в каждом будет выглядеть поиск писем. Пока без реализации. Опирайся на уже сохранённый план.
```

Последний абзац можно заменить своей следующей задачей.
