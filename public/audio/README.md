# Музыка зимнего дома

`winter-house.m4a` — оригинальный инструментальный эскиз, созданный для этого проекта.
Мягкие синтезированные клавиши, челеста и бас в размере 3/4; 72 удара в минуту,
32 такта, 80 секунд. Нет сторонних записей, семплов или заимствованной партитуры.

Исходная партитура и синтез: `scripts/render-winter-music.mjs`.
Готовый AAC-файл хранится в репозитории; сборка не требует аудиоинструментов.
Уровень PCM перед кодированием ограничен пиком 0,32; громкость телефона остаётся
под контролем пользователя. Реверберация обёрнута через границу петли; возможный
небольшой зазор AAC-loop зависит от проигрывателя и требует проверки на iPhone.
