По решению пользователя пятнадцатый подарок исключён. В приложении, рабочем JSON и шаблоне осталось 14 писем. В комнатах 5, 5 и 4 тайника; после четырнадцатой находки доступен стол с 14 конвертами. Все послания утверждены, номера свёртков — 1–14.

Проверено:

- `npm run check:content` — все письма готовы, номера свёртков и ссылки на подарки уникальны.
- `npm test` — 20 из 20. Включён перенос старых сохранений и файлов с 15 письмами: удаляется только бывшее письмо №15, остальные находки, чтение и распаковка сохраняются; повреждённый архив не принимается.
- `npm run build` — TypeScript и production-сборка Vite проходят.
- `npx playwright test --config playwright.build.config.ts` — 20 из 20 в WebKit: профили iPhone 15 Pro с обычной и уменьшенной анимацией. Полный поиск реальными нажатиями, повторный вход, чтение всех 14 утверждённых писем, подпись без обращения, правильные номера свёртков, перенос прогресса, музыка, ошибки загрузки и поворот экрана.
- `git diff --check` — без ошибок.

Это автоматические проверки WebKit; отдельного ручного прохода новой версии на физическом iPhone не было.

Исторический ключ localStorage с `house-15` сохранён для совместимости. Письма и тайника №15 в игровом содержимом нет.
