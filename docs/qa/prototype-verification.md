# Проверка первого прототипа

3 ноября 2026 года. Локальный адрес: `http://127.0.0.1:5173/`. Тестовые действия выполнялись в отдельных браузерных контекстах; пользовательский прогресс не изменялся.

## Проверяемый сценарий

Новый вход → приглашение → подушка → конверт → счётчик 1/1 → стол → текст из JSON и № 12 → отдельная отметка распаковки → перезагрузка → стол → повторное чтение → отмена распаковки.

Это статическое приложение: данные берутся из локального JSON, игровые события сохраняются в браузере. API, серверная база и внешние учётные записи не используются.

## Результаты

| Проверка | Результат |
| --- | --- |
| TypeScript и production build | Успешно, Vite 8.3.5. |
| Автоматические проверки | 10 из 10: правила поиска, порог 15 для полного календаря, отдельные события, восстановление, ошибки хранилища, валидация содержания. |
| Локальный HTTP | 200. |
| Новый вход | Приглашение, счётчик 0/1; конверт недоступен до перемещения подушки. |
| Тайник | Подушка меняет положение; конверт становится отдельной доступной кнопкой. |
| Находка | Конверт исчезает, счётчик 1/1, доступен переход к столу. |
| Письмо | Отображаются послание, подпись и условный № 12 из `content/prototype.json`. |
| Разделение событий | После открытия `openedAt` заполнен, `unwrappedAt` остаётся `null`. |
| Явная распаковка | Записывается только отдельной кнопкой. |
| Перезагрузка | Открывается стол, сохраняются находка, чтение и отметка распаковки. |
| Повторное чтение и отмена | Письмо доступно снова; отмена очищает только `unwrappedAt`. |
| Мобильная эмуляция | 390×844 и 320×568, touch, reduced motion: нет горизонтального переполнения; длинное письмо прокручивается. |
| Короткий экран | Исправлено пересечение конверта и кнопки. На ширине 320px пересечения нет. |
| Ошибочное сохранение | Исходная строка `{broken-demo-save` остаётся неизменной, показывается сообщение. |
| Запрещённый localStorage | Интерфейс продолжает работать, показывает ограничение текущим сеансом. |
| Консоль | Ошибок и предупреждений при проверке нет. |
| Графика и шрифты | Локальные запросы успешны; файлы не зависят от внешнего сервиса во время игры. |

## Границы проверки

Проверен первый прототип с одним письмом в Chromium, включая мобильную эмуляцию. Физические iPhone/Android и Safari ещё не проверены. Поиск 15 писем, остальные комнаты, финальная упаковка, полноразмерный архив и перенос сохранения пока не реализованы. Иллюстрации пока в исходном PNG; оптимизация загрузки предстоит.
