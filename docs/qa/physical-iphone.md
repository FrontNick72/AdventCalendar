Жест прокрутки при 100% остаётся без надёжного подтверждения со стороны инструмента.

## Открыть сборку на телефоне

1. Подключить Mac и iPhone к одной домашней сети Wi-Fi.
2. Из папки проекта запустить `npm run preview:phone`. Команда сначала собирает актуальный сайт, затем показывает локальный адрес и QR-код. Сервер использует фиксированный порт 4173; при занятом порте он завершается, чтобы QR не повёл на другое приложение.
3. Открыть созданный `phone-preview.local/qr.png` на Mac и считать обычной камерой iPhone. Перейти в Safari. Можно вручную набрать адрес из терминала или `phone-preview.local/address.txt`.
4. Оставить Mac включённым и команду работающей на время проверки. Для остановки нажать Ctrl+C.

Это временная проверка по Wi-Fi, без публикации. Сборка обновляется при следующем запуске команды. QR генерируется заново из текущего локального IP; при смене сети или IP повторить запуск. Если найдено несколько сетевых интерфейсов, дополнительные адреса и QR перечислены в терминале.

При недоступности страницы проверить, что оба устройства находятся в одной сети без изоляции клиентов (гостевые сети могут её включать), а macOS разрешает входящие подключения Node.js. Если VPN мешает локальной сети, проверить его настройку доступа к LAN. Переадресация портов роутера не требуется.

Тестовый адрес отличается от `127.0.0.1:5173` и будущего адреса размещения. Их сохранения независимы. Для переноса использовать JSON из настроек. Рабочие тексты и подарочный реестр при проверке не меняются.

## Проход, около 10–15 минут

| Действие | Ожидаемый результат | Результат на телефоне |
| --- | --- | --- |
| Первый вход через QR | Приветствие, сцена с креслом, читаемые надписи | Не проверено |
| Найти 2–3 письма, открыть ещё один тайник без сбора | Счётчик считает только собранные письма, конверт виден отдельно | Не проверено |
| Закрыть вкладку, снова открыть **тот же адрес** в обычном Safari | Комната, находки и открытый тайник восстановлены | Не проверено |
| Перейти во все три комнаты и собрать оставшиеся письма | Все предметы нажимаются; стол доступен только после 15 находок | Не проверено |
| Перейти к столу | Лампа загорается, переход можно пропустить; 15 конвертов доступны | Не проверено |
| Выбрать несколько разных конвертов, открыть и перечитать | Текст соответствует выбору, прокрутка работает; чтение не равно распаковке | Не проверено |
| Повернуть телефон и вернуть вертикально; скрыть/показать панели Safari | Нет обрезанных тайников, кнопок под системными зонами и горизонтальной прокрутки | Не проверено |
| Настройки → «Сохранить прогресс в файл» | JSON сохраняется через системное меню iOS в «Файлы» | Не проверено |
| «Восстановить из файла» → выбрать этот JSON → отменить | Видно сравнение; отмена не меняет прогресс | Не проверено |
| Скачать копию, затем подтвердить сброс поиска и восстановить копию | После явного «Заменить прогресс» возвращаются находки и чтение; после обновления остаются | Не проверено |
| Включить iOS «Уменьшение движения», из стола вернуться в дом и снова к столу | Длительного перехода нет, все конверты доступны сразу | Не проверено |

Сейчас письма черновые. Кнопки распаковки у них **не должно быть**. После заполнения финальных текстов нужно повторить чтение длинного письма, увеличить текст в Safari, сверить номера с физическими свёртками и проверить отметку распаковки с отменой. В автоматическом тесте для этого используется отдельное временное содержание, не авторский JSON.

Перед сбросом обязательно сохранить копию. Не использовать частный режим для проверки сохранения между посещениями. После финального размещения повторить вход через постоянный QR и перенос сохранения: локальный QR для коробки не подходит.
