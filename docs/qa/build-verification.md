# Готовая сборка и подготовка проверки на iPhone

Дата: 4 ноября 2026 года. Целевое устройство: iPhone 15 Pro.

## Что проверено

Путь: готовые файлы из `dist/` → Safari-совместимый WebKit с профилем iPhone → 15 реальных находок → стол и чтение → локальное сохранение → JSON-файл → новый браузер → подтверждение восстановления → перезагрузка.

`npm run test:iphone:build` выполняет сборку и поднимает отдельный Vite preview на порту 4183. Сервер разработки 5173 не используется. Конфигурация повторно использует существующие сценарии без дублирования; тест с подменой исходного JSON-модуля исключён, поскольку он предназначен для dev-сервера. Дополнительно проверены задержанные загрузки изображений и повторная загрузка комнаты после сетевого сбоя.

Результаты:

- `npm test`: **19/19** проверок логики, содержания и сохранений.
- TypeScript и Vite build: успешно.
- `npm run test:iphone:build`: **16/16**, WebKit, обычная и уменьшенная анимация, около 1,2 минуты.
- Полный поиск и повторный вход: находки и прочитанные письма сохраняются.
- Файловый перенос: фактическое скачивание и импорт в новый браузер, предварительный просмотр, отмена и подтверждение.
- Неподходящие файлы, повреждённое сохранение и отказ записи: исходные данные сохраняются.
- Ошибки картинки стола: переход освобождает управление; уменьшение движения тоже завершает его.
- Дополнительный сценарий: задержка запросов к ресурсам 350 мс, успешное декодирование фона; сбой следующей комнаты → повтор → восстановленная комната и та же находка. Это задержка, не моделирование пропускной способности мобильной сети.
- В дополнительном сценарии все запросы идут на локальный адрес; ошибок JavaScript и горизонтального переполнения нет.
- Черновые письма не предлагают распаковку; состояние распаковки отдельно проверено восстановлением архива. Длинное готовое письмо и кнопка распаковки проверяются существующим dev-тестом с временным содержанием.

## Локальный доступ с телефона

Добавлен `npm run preview:phone`: актуальная сборка, порт 4173, проверка занятого порта, адрес домашней сети и PNG QR-кода. QR создаётся локально библиотекой `qrcode`, без внешнего сервиса. Адреса и QR лежат в игнорируемой папке `phone-preview.local`, вне `public/` и `dist/`.

На этом Mac получен HTTP 200 по LAN-адресу, который записан в текущий QR. Это подтверждает запуск и сетевой адрес со стороны компьютера. Доступ с iPhone, настройки роутера и системное меню iOS этим не подтверждены. Проверочный сервер после проверки остановлен; для телефона его запускают командой выше.

Инструкция и таблица фактических результатов: [physical-iphone.md](physical-iphone.md).
