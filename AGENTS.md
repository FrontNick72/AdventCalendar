1. Цель проекта
Я собираю персональный новогодний Адвент-календарь для своей жены Даши.

Подарки должны быть разнообразными.
Желательно чередовать практичные вещи, косметику, сладости, коллекционные предметы и впечатления.

Несколько подарков можно объединять по смыслу, но каждый сюрприз должен иметь отдельный номер.
Впоследствии нужно распределить подарки по дням так, чтобы интерес постепенно нарастал.
Необходимо отслеживать, что уже куплено, что только выбрано и что ещё нужно найти.

Не придумывать факты о Даше.
Не считать предложенную идею уже купленным подарком.

Для коллекционного мерча отличать официальную продукцию от фанатских реплик.

Не распределять подарки по дням, пока я отдельно не попрошу.
